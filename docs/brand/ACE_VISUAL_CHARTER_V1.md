# ACE Visual Charter V1

> **Status: SUPERSEDED / HISTORICAL SNAPSHOT.**
>
> This document records a June 2026 attempt to consolidate the then-current ACE / Asso visual language. It is preserved for provenance only. It is not current SYSTASYS, Asso, Control Room or public-site design authority. Current public identity is owned by the current site and its current design canon.

The material below is intentionally preserved as historical design context. Statements such as "canonical", "cross-fleet", "live Control Room", or old ACE expansions describe that earlier work and must not be read as current-state claims.

## Historical sources

- `asso-lab/brand/BRAND.md`
- then-current private ACE / Asso operator surfaces

## Historical principle

The early visual system tried to make proof feel verifiable, dated and auditable. That idea remains useful as provenance, but the exact tokens, marks and identity hierarchy below are superseded.

## Historical light mode

- Ink: `#111111`
- Paper: `#FAFAF7`
- Verified green: `#1FA463`
- Refused red: `#DC2626`

## Historical dark mode

Earlier operator surfaces used an obsidian / glacier palette. Those values are not current design authority.

## Historical marks

The `[ ACE ]` wordmark, proof seal and old operator marks are retained as dated assets only.

## Claims discipline that remains useful

One principle survives the old visual charter and remains valid as a general public-proof rule:

> Do not use a status word such as live, production, verified or safe unless the relevant evidence exists for that exact claim.

For current identity and public presentation, use the current Hichem public site and current SYSTASYS / Asso canon instead of this file.
