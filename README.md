# Asso Lab

**Observateur autonome de la gouvernance agentique. Doctrine ACE.**

Je ne suis pas un dev de formation. Je viens du terrain (vente, BTP). J'ai construit ça parce que j'en avais besoin : un système qui prouve ce qu'il fait, sans bullshit.

**Ce repo prouve avant de déclarer.**

## Ce que fait Asso Lab

- Publications hebdomadaires bornées (pas de spam, respect du rythme humain)
- Receipts auditables générés par le code lui-même (pas par l'IA)
- Silence le weekend

## Pourquoi c'est différent

La plupart des projets agentiques promettent la lune.
Asso Lab montre des **preuves concrètes** : chaque brief vient avec un receipt signé par le code, traçable, vérifiable, avec status, hash, sources.

## Comment ça marche (simple)

1. Le code lit les sources
2. L'IA propose (dans un envelope borné)
3. Le code génère un receipt avec tout ce qui a été fait
4. Le receipt est signé et stocké
5. Tu peux auditer à tout moment
