## The publishing pipeline

### Full automated run (one command)

```bash
python run_pipeline.py
```

Flow:
1. briefing_orchestrator_v0.py generates today's brief (DRAFT, committed)
2. telegram_gate.py sends the X post draft to Asso_CM bot
3. Hichem replies "ok" to approve or "non" to refuse
4. If approved: post_to_x.py posts to X + generates Proof of Agent receipt
5. Receipt committed to proof-of-agent/receipts/

### Manual steps (fallback)

```bash
# 1. Generate brief
python briefing_orchestrator_v0.py

# 2. Draft and gate an X post
python telegram_gate.py --file drafts/x_post.txt --channel X

# 3. Post if approved
python post_to_x.py --file drafts/x_post.txt
```

### Gate keywords

Approve: ok, oui, valide, go, yes, 1, approve, post
Refuse:  non, no, refuse, annule, stop, 0, cancel, nope

## Comms format: ACE Field Note

Source of truth: docs/comms-field-note-format.md

### X post (EN, solo, max 280 chars)

1. Contrarian hook (stops the scroll)
2. 2-3 lines: insight through R.O.C lens
3. Proof when possible (number, fact, or receipt screenshot)
4. Final line: principle, usually a variant of "Receipts over claims."

Post solo first. Thread only once traction appears.
Series label: ACE Field Note #N (increment per published brief).

### LinkedIn post (FR)

1. Hook, same contrarian energy, in French
2. Short paragraphs, one idea each, generous white space
3. R.O.C angle as a point of view
4. Proof or concrete example
5. Close on the principle
6. No links in body (first comment only)

### One brief = four formats

X post (EN) + thread (EN) + LinkedIn (FR) + newsletter snippet.
Produce all four in one session run.

## Doctrine pillars (for content and code)

- Closed by Default: nothing allowed unless explicitly admitted
- Evidence First: receipts over claims
- Human Bounds: agents propose, humans decide
- Fail-Closed: when in doubt, stop and surface the reason

Counter-position on competitors:
- Observability tools: they watch what happened. ACE governs what is allowed.
- Runtime guardrail tools: they filter what the agent can do. ACE decides who has the right to ask.
- Compliance platforms: they prove you have policies. ACE proves your agents respect them.
See "Concurrents suivis" table below for current names, wedges, and last-updated dates.
