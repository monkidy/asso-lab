# Project status

## Current status

```text
PUBLIC_PROOF_SURFACE_V1
```

Asso Lab is a bounded public proof surface derived from the broader Asso / SYSTASYS work.

It shows public doctrine, bounded briefs, receipts, examples and audit trails. It is not the current SYSTASYS runtime, not a current operations mirror, and not a source of live system truth.

## Historical naming

```text
HISTORICAL_NAME_PRESENT != CURRENT_PARENT_IDENTITY
```

The historical receipt/admissibility material may be reused as a governance layer. It does not define the current parent identity of Asso or SYSTASYS.

## What is public here

- public receipt and governance doctrine;
- public briefings and dated publications;
- public receipts for those artifacts;
- static action receipt examples;
- public-safe validation and proof material;
- historical material whose provenance is useful.

## What is intentionally not current here

The June-era social publishing pipeline and its operator routines are not part of the current public surface.

Current public communication, private SYSTASYS operation and live state have separate owners.

## What remains private

This repository does not expose:

- the current private SYSTASYS runtime;
- current infrastructure or terrain state;
- broker or economic state;
- private operator controls;
- private safety envelopes;
- credentials or secrets;
- trading, wallet, deployment, merge, send or publishing authority.

## What this repo can prove

This repo can prove public artifacts that exist in git and the evidence attached to them.

## What this repo cannot prove by itself

This repo cannot prove production readiness, formal verification, live runtime safety, private implementation safety, client adoption, revenue or autonomous permission-to-act.
