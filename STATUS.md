```text
PUBLIC_OBSERVER_SURFACE_V0
```

Asso Lab is a public observer surface for ACE.

It shows public doctrine, bounded briefs, code-generated receipts, examples, and audit trails.

## What is public here

- Public ACE doctrine.
- Public briefings.
- Public receipts for those briefings.
- Static action receipt examples.
- Scripts supporting the public proof surface.
- Public communication and brand documentation.

## What remains private

The full runtime remains private.

This repository does not expose:

- full private execution engine;
- private operator controls;
- private safety envelopes;
- private runtime state;
- private credentials or secrets;
- trading, wallet, deployment, merge, send, or publishing authority.

## What this repo can prove

This repo can prove public artifacts that exist in git:

- a brief file exists;
- a receipt file exists;
- a receipt contains inspectable fields;
- a script exists to generate or support the public artifact;
- a public doctrine statement exists;
- action receipt examples exist.

## What this repo cannot prove by itself

This repo cannot prove:

- production readiness;
- formal verification;
- live runtime safety;
- private implementation safety;
- client adoption;
- revenue;
- autonomous permission-to-act.

Those claims require separate evidence.
