# Brand kit: ACE / Asso Lab

The visual identity for ACE, Asso Lab, and Proof of Agent. One idea drives it:
this is the proof layer for AI agents, so the brand looks like verifiable proof.
Ink on paper, monospace, a verification seal. Serious and technical, never flashy.

## Concept
"The proof layer for AI agents." Everything looks dated, signed, auditable.

## Colors
- Ink: `#111111` (primary text, marks)
- Paper: `#FAFAF7` (background)
- Signal green: `#1FA463` (verified, allow, pass)
- Refused red: `#DC2626` (deny, fail-closed, reserved for "blocked" states)

Rule: green means allowed/verified, red means refused. The two-state accent
mirrors the gate doctrine (allow versus deny).

## Type
- Monospace for the brand, marks, hashes, receipts: JetBrains Mono (or IBM Plex Mono).
  Mono signals code and proof.
- Sans for body and headlines: Inter.

## Marks
- Wordmark: `[ ACE ]` with the brackets in green. The brackets encode "bounded execution".
- Seal: a stamped double ring with a green check, meaning "Proof of Agent". Use it as
  the signature mark and as a watermark on proof screenshots.

## Assets in this folder
- `wordmark.svg`
- `proof-seal.svg`
- `x-banner.svg` (1500x500, X header)

## Usage notes
- These SVGs use system fonts. For a pixel-perfect production logo, install JetBrains
  Mono, or outline the text to paths in a vector tool.
- To get a PNG (X banner or avatar), open the SVG in a browser and export, or import
  into Canva.
- Keep it minimal. Whitespace is part of the brand. No gradients, no flashy effects.

Receipts over claims.
