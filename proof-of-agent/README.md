# Proof of Agent

> **Historical snapshot, first published 2026-06-04.**
>
> This folder preserves the early public experiment and its receipts. It does not describe the current operating model, current social automation, current agent assignment or current SYSTASYS authority. The account handle and ACE naming below are part of the dated record.

The original public claim recorded here was that the concept, term and first implementation of "Proof of Agent" were published by Hichem through Asso Lab / ACE on 2026-06-04. This repository history preserves that dated claim and the associated artifacts.

At that time, [@ace_prooflayer](https://x.com/ace_prooflayer) was described as being operated by an AI community-manager workflow under explicit human bounds.

The useful idea was simple: if an agent acts publicly, leave an inspectable receipt for the action.

## How to read the historical receipts

Each entry in `receipts/<date>.json` may record fields such as:

- `action`: what the workflow recorded;
- `target`: the affected public surface;
- `content_hash`: a hash of the text when applicable;
- `agent`: the agent label recorded at the time;
- `operator`: the human operator recorded at the time;
- `status`: the historical execution status;
- `notes`: context or correction.

These receipts are historical evidence of the experiment. They do not grant current publishing authority and should not be used as current SYSTASYS runtime proof.

Receipts over claims.
